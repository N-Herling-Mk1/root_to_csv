# root2csv - FEATURE FILTER / DROP LIST
# ---------------------------------------------------------------------------
# One branch name per line. These branches are removed from the filtered CSV.
# The canonical parquet is NEVER modified - it stays the complete master copy.
#
# RULES
#   - Blank lines and lines starting with # are ignored.
#   - Inline comments after a name are allowed:   jet_pt_NOSYS   # too wide
#   - Names are matched against branch names in <name>_manifest.json,
#     NOT against CSV column headers. One branch may expand to many columns.
#   - Shell-style globs are allowed and resolve against manifest branch names:
#         caloCluster_*        drops every caloCluster branch
#     Globs are convenient but opaque in review - prefer explicit names for
#     anything that encodes a physics decision.
#   - A name this file does not contain is SKIPPED with a printed warning
#     (and listed in the UNMATCHED section of the drop report). Samples do
#     not all carry the same branches. --strict makes it an error instead.
#
# To add or remove a feature: edit this file and re-run dropfilter.py against
# the parquet. No re-conversion from ROOT is needed.
# ---------------------------------------------------------------------------
